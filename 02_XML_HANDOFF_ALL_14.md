### Тени / обводки / внешняя рамка

- Два слоя: (x=0,y=6,blur=17,alpha=12%) и (x=0,y=1,blur=3,alpha=3.5%), spread=0; стиль `ENOT / Elevation / Featured Card`.
- **402 × 874 px**, radius=28 px, stroke=1 px на внешнем фрейме — способ **презентации экранов в Figma**, **не инструкция делать рамку и тень вокруг всего Android Activity**. В Android переносить реальные внутренние элементы; граница устройства не является экранным UI.
- Крупные карточки — мягкая тень; обычные — тонкая обводка. XML: `shape`/`selector`/`elevation` в зависимости от элемента и существующей реализации.
- Градиенты: 11 Paint Styles `ENOT / Gradient / …` присутствуют в общей системе. Для XML требуется точно перенести направление/stops; **не заменять нативные состояния неподтверждёнными градиентами**.

## 3. Реализация в существующем Android XML

| UI-блок | XML-реализация: принцип, не новый код |
|---|---|
| Цвета/типографика | `res/values/colors.xml`, `styles.xml`, `dimens.xml` — только после чтения текущих ресурсов |
| Кнопка | Существующая View/Button, drawable background, selector для состояний |
| Карточка уровня/занятия | Существующие layouts, drawable/состояние и контент; не заменять навигацию |
| Выражение | `TextView` и текущая композиция; не импортировать целиком как PNG |
| Числовые ответы | 6 кликабельных нативных элементов; тексты и проверки из domain |
| Сравнение | 3 кликабельные кнопки знаков; состояние после нажатия |
| Таймер/прогресс | Нативные элементы, значения из действующего состояния сессии |
| Обратная связь | Нативные состояния и тексты из `strings.xml`; не дублировать бизнес-логику |
| Иллюстрации | `res/drawable-nodpi/` для raster при сохранении исходного масштаба; SVG требуется конвертировать в VectorDrawable или использовать другой поддерживаемый нативный вариант после проверки |
| Общая шапка | Одно переиспользуемое XML-оформление/компонент, где требуется; не показывать на экранах, где его нет в исходнике |

## 4. Проверка реализации (проводит владелец)

Сборка/тесты в Android Studio: `assembleDebug`, `testDebugUnitTest`; ручная проверка восьми + шести сценариев, возвращения назад, состояний нажатия, 500 мс подсветки **только если подтверждено действующей логикой**, таймеров и результата. Сравнить каждый экран на телефоне с Figma и не объявлять готовность до реальных результатов.

## 5. Ограничения

**Не подтверждены:** conversion Figma px→dp/sp, точные размеры Android Insets, отображение с увеличенным шрифтом, языковые варианты, фактические действующие правила уровня, ресурсное качество экспортов, исходный XML-код. Эти параметры нельзя выбирать произвольно: сначала сверка проекта, затем только точечное обновление UI.
