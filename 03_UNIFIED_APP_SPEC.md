# СчётЕнот · Единая спецификация приложения · ENOT v1.1

## Объект передачи

Единый визуальный контракт 14 экранов **СчётЕнота** — Android XML Views: 2 общих + 6 арифметики + 6 сравнения. [Figma redesigned screens](https://www.figma.com/design/BRMSwONxGEshJOAghaAqjz/MY-APP-%E2%80%94-UX-UI-Mobile-App?node-id=81-1125). [ENOT Design System](https://www.figma.com/design/BRMSwONxGEshJOAghaAqjz/MY-APP-%E2%80%94-UX-UI-Mobile-App?node-id=69-1117).

Визуальная система общая с **СпикЕнотом** (там Jetpack Compose), но СчётЕнот остаётся XML-приложением. Не переписывать XML на Compose, не изменять архитектуру, domain/data, навигацию и вычислительную логику.

## Навигационная структура (сценарии)

- **Общий вход:** Приветствие → Главный хаб → выбранное направление.
- **Арифметика:** Выбор занятия → Правила → Выбор уровня → Игра → Результат (успех **или** неудача).
- **Сравнение:** Правила → Выбор сложности → Игра → Подсветка/объяснение после ответа → Результат (успех **или** неудача).
- Макеты успеха и неудачи — альтернативные, не последовательные экраны. Не добавлять «экран после ответа» в арифметику только ради совпадения количества макетов.

## Фирменные элементы

- Обязательный исходный логотип — **`logo_schetenot`** из `PICTURE and LOGO and DECOR`, а не картинка `raccoon_smile`.
- Общий компонент шапки Figma: [ENOT / Header / SchetEnot Brand](https://www.figma.com/design/BRMSwONxGEshJOAghaAqjz/MY-APP-%E2%80%94-UX-UI-Mobile-App?node-id=100-1160). В четырёх макетах используются связанные экземпляры. 
- В шапке: логотип 72 × 72 px, отдельный текст «Счёт» синий #0755B8 и «Енот» оранжевый #F58A00; подпись **«Математика — легко и интересно!»**; справа звёзды (отдельный декор экрана).
- Размер самого визуального блока шапки — 354 × 58 px; не считать этот размер абсолютным требованием Android для всех плотностей.
- Еноты и математический декор — отдельные изображения с прозрачностью; не копировать полный скриншот как иллюстрацию.

## Состояния компонентов

| Компонент | Что сохранять |
|---|---|
| Занятие | Доступно, выбранное/развёрнутое, заблокировано (по фактическому продукту) |
| Уровень | Default / Selected; остальные состояния только если есть в исходнике |
| Ответ арифметики | 6 чисел, состояние ответа, подсветка и объяснение по действующей логике |
| Ответ сравнения | `<`, `=`, `>`; до/после выбора; блокировка ввода во время обратной связи по действующей логике |
| Прогресс | Нативная шкала, значение вычисляется из реального состояния сессии |
| Таймер | Динамическое значение по реальному доменному уровню |
| Результат | Альтернативные success / failure; минимум и точность — независимые проверки |
| Primary CTA | Синий #0755B8; не превращать жёлтый/оранжевый в конкурирующие основные CTA |

## Локализации, строки и доступность

- Все UI-тексты — в `strings.xml` и существующих локализациях проекта; графическое имя логотипа не заменяет строковые ресурсы в доступности.
- Декоративные изображения не должны создавать лишние объявления TalkBack; смысловые кнопки иметь текст и удобную touch-area.
- Минимальный контраст, масштабирование шрифта и доступность конкретной XML-разметки **не проверялись**.

## Конфликты, подлежащие решению владельца

1. **Выбор занятия — решение владельца от 17.11.2026:** Сложение, Вычитание, Умножение и Деление доступны. Figma показывает устаревшие «Скоро» для трёх операций; их не переносить в XML. Сохранить single-selection: одна развёрнутая карточка, остальные свёрнуты. Перед изменениями проверить действующий код и устранить только визуальное расхождение.
2. **Геометрия:** в макетах 402×874 px, перенос в dp/sp не обоснован без сверки Android layout, density/insets. 
3. **Ресурсы:** не считать SVG напрямую доступным в Android; конверсия/тест на устройстве обязательны.
4. **Семантическая палитра:** не все operation/success токены уточнены; оставить специализированные оттенки как в исходниках до согласования.

## Контрольная передача в Codex

Разрабатывать по одному проверяемому шагу: **сначала** сверка существующего проекта и визуальных ресурсов, **затем** styles/colors/dimens, **после** общие компоненты, **потом** 2 общих экрана, арифметика, сравнение; завершить сборкой и визуальной проверкой на телефоне. Не генерировать новый проект, не вводить DI/Room/Compose, не менять игровые алгоритмы. Codex не запускает сборку, тесты, commit или push; результаты подтверждает владелец.
